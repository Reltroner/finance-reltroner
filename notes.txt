================================================================================
CATATAN: CARA MEMERIKSA STRUKTUR PROJECT DAN GENERATE structure.txt
================================================================================

TUJUAN:
Membuat daftar lengkap file proyek (termasuk .gitignore) ke dalam file 
structure.txt, dengan format yang rapi dan tersortir.

================================================================================
METODE 1: MENGGUNAKAN GIT (REKOMENDASI) ⚡
================================================================================

Cara cepat dan akurat untuk file yang dicatat Git.

Langkah-langkah:
1. Buka PowerShell di root project:
   cd C:\laragon\www\finance-reltroner

2. Jalankan perintah:
   git ls-files | Sort-Object | Set-Content -Encoding utf8 structure.txt

Kelebihan:
- Hanya menampilkan file yang dicatat Git (termasuk .gitignore, .editorconfig, dll)
- Format path menggunakan / (forward slash)
- Output clean dan sesuai dengan yang perlu dideploy
- Cepat dijalankan

Hasil: File structure.txt berisi daftar file Git-tracked, sorted A-Z.

================================================================================
METODE 2: MENGGUNAKAN POWERSHELL (SEMUA FILE) 🔧
================================================================================

Untuk menampilkan SEMUA file (termasuk untracked), gunakan:

Perintah lengkap:
---
Get-ChildItem -Recurse -Force -File -ErrorAction SilentlyContinue |
  Where-Object { $_.FullName -notmatch '\\.git\\' } |
  ForEach-Object { $_.FullName.Substring((Get-Location).Path.Length+1) -replace '\\','/' } |
  Sort-Object |
  Out-File -Encoding utf8 structure.txt
---

Penjelasan parameter:
- -Recurse       : Scan semua subfolder
- -Force         : Tampilkan file tersembunyi (dotfiles seperti .gitignore)
- -File          : Hanya file (tidak folder)
- -ErrorAction   : Abaikan error permission
- Where-Object   : Exclude folder .git untuk menghindari noise
- ForEach-Object : Konversi path ke relative dan gunakan / bukan \
- Sort-Object    : Urutkan alphabetically
- Out-File       : Simpan ke file dengan encoding UTF-8

Kelebihan:
- Menampilkan ALL file di filesystem, termasuk node_modules, vendor, dll
- Tidak perlu Git init
- Include semua file untracked

================================================================================
METODE 3: DENGAN FILTER TAMBAHAN 🎯
================================================================================

Jika ingin exclude folder tertentu (vendor, node_modules, etc):

PowerShell:
---
Get-ChildItem -Recurse -Force -File -ErrorAction SilentlyContinue |
  Where-Object { 
    $_.FullName -notmatch '\\(vendor|node_modules|\.git)\\' 
  } |
  ForEach-Object { 
    $_.FullName.Substring((Get-Location).Path.Length+1) -replace '\\','/' 
  } |
  Sort-Object |
  Out-File -Encoding utf8 structure.txt
---

Custom exclude list:
- vendor           : Library Composer
- node_modules     : Library NPM
- .git             : Folder Git (sudah di-exclude)
- storage/logs     : Log files (optional untuk exclude)
- storage/framework/cache : Cache files (optional)

================================================================================
VERIFIKASI & TROUBLESHOOTING 🔍
================================================================================

1. Cek hasil struktur (baca 60 baris pertama):
   Get-Content structure.txt | Select-Object -First 60

2. Hitung jumlah file:
   (Get-Content structure.txt | Measure-Object).Count

3. Cek apakah .gitignore ada di daftar:
   Get-Content structure.txt | Select-String "\.gitignore"

4. Export ke CSV untuk analisis:
   Get-Content structure.txt | ConvertFrom-Csv -Delimiter ',' | Export-Csv files.csv

REKOMENDASI

================================================================================
BONUS: AUTOMATION SCRIPT
================================================================================

Buat file: generate-structure.ps1

Isi:
---
# Script untuk generate structure.txt otomatis
param(
    [string]$Method = "git",  # "git" atau "powershell"
    [string]$ExcludeFolders = "vendor|node_modules"
)

$ProjectPath = Get-Location

if ($Method -eq "git") {
    # Metode Git
    Write-Host "Generating structure using Git..." -ForegroundColor Green
    git ls-files | Sort-Object | Set-Content -Encoding utf8 structure.txt
} else {
    # Metode PowerShell dengan exclude filter
    Write-Host "Generating structure using PowerShell..." -ForegroundColor Green
    Get-ChildItem -Recurse -Force -File -ErrorAction SilentlyContinue |
      Where-Object { $_.FullName -notmatch "\\($ExcludeFolders|\.git)\\" } |
      ForEach-Object { $_.FullName.Substring($ProjectPath.Path.Length+1) -replace '\\','/' } |
      Sort-Object |
      Out-File -Encoding utf8 structure.txt
}

Write-Host "✓ structure.txt generated successfully!" -ForegroundColor Green
Get-Content structure.txt | Measure-Object | Select-Object @{Name="Total Files";Expression={$_.Count}}
---

Cara menggunakan:
.\generate-structure.ps1 -Method "git"
.\generate-structure.ps1 -Method "powershell" -ExcludeFolders "vendor|node_modules|storage"
